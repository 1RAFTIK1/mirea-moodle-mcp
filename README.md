# mirea-moodle-mcp

MCP-сервер, который подключает ИИ-агентов к СДО РТУ МИРЭА ([online-edu.mirea.ru](https://online-edu.mirea.ru)): **Claude Desktop, Claude Code, Cursor, VS Code (Copilot), Cline, Windsurf, Gemini CLI, Codex CLI, LM Studio, Zed**. Есть HTTP-режим для **ChatGPT** и **claude.ai** ([подробно](docs/CLIENTS.md)).
После установки можно просто спросить агента:

- «какие у меня дедлайны на этой неделе?»
- «что задано по большим данным и какие файлы приложены к заданию?»
- «скачай лекции по ИСУДД в Загрузки»
- «загрузи ~/Documents/отчёт.pdf в практическую работу 2»
- «что у меня сегодня?», «что нового в Moodle?», «какие оценки по ИСУДД?»

Плюс локальный **дашборд**: новые уведомления, дедлайны, лекции твоей группы (с записями и прогнозом следующей), открытые тесты, курсы. И **подписка на календарь**: дедлайны и лекции сами появятся в Google/Apple/Яндекс Календаре (`mirea-moodle-mcp calendar`).

> Неофициальный проект студентов, к МИРЭА отношения не имеет. Работает только с твоим аккаунтом и только с тем, что ты и так видишь в браузере.

### Чего проект НЕ делает — и не будет

Это органайзер учёбы, а не способ учиться за тебя:

- **не проходит тесты** — только показывает сроки, попытки и оценки;
- **не отмечает посещаемость** и не «сидит» на лекциях вместо тебя — только напоминает и даёт ссылку;
- **не пишет работы за тебя и не сдаёт их без твоей команды** — загружает файлы, которые ты указал(а).

Pull request'ы с такими функциями приниматься не будут.

## Установка (≈ 3 минуты)

Нужен любой клиент с поддержкой MCP — например [Claude Desktop](https://claude.ai/download), Cursor, VS Code или Gemini CLI.

### macOS / Linux

Открой Терминал и выполни:

```sh
curl -fsSL https://raw.githubusercontent.com/1RAFTIK1/mirea-moodle-mcp/main/install.sh | sh
```

### Windows

Открой PowerShell и выполни:

```powershell
irm https://raw.githubusercontent.com/1RAFTIK1/mirea-moodle-mcp/main/install.ps1 | iex
```

Установщик скачает программу и запустит настройку `setup`. Она проведёт по трём шагам:

1. **Сессия Moodle** — если найден Chrome, Яндекс, Edge или другой Chromium-браузер, `setup` предложит расширение: зарегистрирует его, покажет, как загрузить (один раз), откроет Moodle и сам дождётся нажатия «Подключить». Без браузера или по Enter — старый способ через DevTools (подробно — ниже).
2. **Подключение к агентам** — программа найдёт установленные клиенты (Claude, Cursor, VS Code, Gemini CLI, Codex…) и пропишет себя в их конфиги. Старые конфиги сохранятся рядом как `.bak-…`.
3. **Дашборд** — откроется страница с твоими дедлайнами.

После этого **перезапусти подключённые приложения** (Claude Desktop — полностью, через Quit) — в списке инструментов появится `mirea-moodle`.

## Как достать MoodleSession

Сервер не знает твой пароль и не проходит SSO сам — он работает через сессию, которую ты открыл(а) в браузере.

### Способ 1: расширение браузера (без DevTools)

Для Chrome, Яндекс Браузера, Edge, Brave, Vivaldi, Arc. Firefox и Safari пока не поддерживаются.

Его предлагает `setup` при установке. Если пропустил(а) — в любой момент:

```sh
mirea-moodle-mcp extension
```

Команда зарегистрирует программу в найденных браузерах и распакует расширение в папку с настройками (на macOS откроет её в Finder). Затем один раз:

1. открой `chrome://extensions` (Яндекс: `browser://extensions`, Edge: `edge://extensions`) и включи **«Режим разработчика»**;
2. **«Загрузить распакованное расширение»** → выбери папку `extension` (или перетащи её на страницу);
3. войди на <https://online-edu.mirea.ru/> и нажми у значка **Moodle MCP** кнопку **«Подключить»**.

Дальше при каждом новом входе в Moodle расширение само передаёт новую cookie программе, значок показывает ✓ или !. В окошке расширения видны **4 ближайших дедлайна** (срок, курс, сколько осталось; клик открывает задание) и число просроченных. Как это работает:

- расширение читает только cookie `MoodleSession` сайта online-edu.mirea.ru и передаёт её **локально** через Native Messaging: браузер сам запускает `mirea-moodle-mcp`, сеть и открытые порты не нужны;
- запустить программу так может только это расширение (его ID записан в `allowed_origins`);
- программа проверяет cookie в Moodle и сохраняет её, только если вход действительно выполнен: анонимная cookie до входа рабочую сессию не затрёт;
- расширение не хранит значение cookie, только её SHA-256, чтобы не отправлять одно и то же повторно.

После обновления программы снова выполни `mirea-moodle-mcp extension` и нажми «Обновить» на странице расширений. Удалить связку: `mirea-moodle-mcp extension uninstall`.

### Способ 2: вручную через DevTools

1. Зайди на <https://online-edu.mirea.ru/my/> и войди как обычно (логин, пароль, код с почты).
2. Открой инструменты разработчика на этой вкладке:

   | Браузер | Где найти |
   |---|---|
   | Chrome / Яндекс / Edge / Arc | `F12` (на Mac `⌥⌘I`) → **Application** → **Cookies** → `https://online-edu.mirea.ru` |
   | Firefox | `F12` → **Хранилище** → **Куки** → `https://online-edu.mirea.ru` |
   | Safari | Настройки → Дополнения → «Показывать меню Разработка», затем `⌥⌘I` → **Хранилище** → **Cookies** |

3. Найди строку **`MoodleSession`**, скопируй её **Value** (строка из ~26 букв и цифр).
4. Вставь в терминал, когда `setup` попросит.

⚠️ Это значение — временный ключ к твоему аккаунту. Не отправляй его никому (и в чаты тоже).

### Когда сессия протухнет

Moodle завершает сессию через 2 часа бездействия (сколько осталось — `mirea-moodle-mcp doctor`) или при выходе из аккаунта. Claude скажет «сессия истекла». С расширением достаточно снова войти на online-edu.mirea.ru (или нажать «Подключить»). Без него:

```sh
mirea-moodle-mcp cookie <новое значение MoodleSession>
```

Перезапускать агента не нужно — запущенный сервер сам подхватит новую сессию. Пока сервер запущен, он раз в 10 минут «трогает» сессию, чтобы она не истекала от простоя.

> Если выйти из аккаунта в браузере кнопкой «Выход», сессия умрёт и у сервера. Просто закрой вкладку.

## Команды

| Команда | Что делает |
|---|---|
| `mirea-moodle-mcp setup` | первая настройка целиком |
| `mirea-moodle-mcp cookie <значение>` | обновить сессию |
| `mirea-moodle-mcp extension [uninstall\|path]` | расширение браузера: кнопка «Подключить» и автообновление cookie |
| `mirea-moodle-mcp status` | проверить, жива ли сессия |
| `mirea-moodle-mcp doctor` | диагностика: сеть до online-edu (в т. ч. VPN), сессия, группа, разрешённые папки, подключённые клиенты |
| `mirea-moodle-mcp roots [add\|rm <папка>]` | папки, из которых можно сдавать файлы и куда можно скачивать |
| `mirea-moodle-mcp dashboard` | собрать и открыть дашборд |
| `mirea-moodle-mcp today` / `week` | план на сегодня / на 7 дней: лекции, сроки сдачи, тесты |
| `mirea-moodle-mcp calendar` | адрес подписки на календарь Moodle (Google / Apple / Яндекс) |
| `mirea-moodle-mcp group ИКБО-50-23` | задать группу (фильтр лекций) |
| `mirea-moodle-mcp clients` | какие агенты/IDE поддерживаются и какие найдены |
| `mirea-moodle-mcp install <id\|detected>` | подключить к клиенту (`claude-desktop`, `claude-code`, `cursor`, `vscode`, `cline`, `windsurf`, `gemini`, `codex`, `lmstudio`, `zed`) |
| `mirea-moodle-mcp config <id>` | фрагмент конфига для ручной вставки |
| `mirea-moodle-mcp http` | MCP по HTTP для ChatGPT, claude.ai и других удалённых клиентов |

## Инструменты

| tool | что делает |
|---|---|
| `list_courses` | курсы: текущие / все / прошедшие / будущие |
| `course_contents` | разделы и элементы курса (задания, файлы, папки, тесты…) |
| `deadlines` | невыполненные дедлайны: просроченные и ближайшие |
| `get_activity` | открыть элемент: текст задания, сроки, приложенные файлы, статус сдачи и оценка; файлы папки; текст страницы |
| `download_file` | скачать файл (по умолчанию в `~/Downloads/mirea`; существующий файл не перезаписывается — сохранится как «имя (1)») |
| `read_text` | прочитать html/txt/csv прямо в чат |
| `submit_assignment` | загрузить файлы/текст в задание; `dry_run=true` — только проверить загрузку, ничего не сохраняя; `finalize=true` — отправить на проверку (агент обязан спросить) |
| `quizzes` | трекер тестов: срок, лимит времени, попытки, оценка, состояние (только чтение — тесты не проходит) |
| `lectures` | расписание лекций MTS Link по твоей группе: идёт сейчас (ссылка «Подключиться»), ожидается (прогноз по регулярности), записи прошедших |
| `agenda` | план на день/неделю из календаря Moodle: вебинары своей группы, сроки сдачи, открытие/закрытие тестов |
| `whats_new` | уведомления Moodle: скоро срок, дайджест заданий на неделю, открытие тестов, оценки и отзывы, форумы |
| `grades` | оценки: сводка по курсам или журнал курса (каждая работа/тест, оценка, диапазон, отзыв) |
| `calendar_feed` | адрес iCal-подписки на календарь Moodle (в HTTP-режиме не выдаётся — это секрет) |
| `coursework` | статус темы курсовой: моя тема, утверждена ли, свободные темы (только чтение — тему не выбирает) |
| `retakes` | пересдачи: графики консультаций и пересдач по кафедрам |
| `dashboard` | открыть дашборд |
| `session_status` | проверить сессию и сколько она проживёт без активности |

`submit_assignment` **заменяет** ранее загруженные файлы. Во многих курсах МИРЭА черновиков нет: сохранённый ответ **сразу считается отправленным на оценку**. Первый раз попроси сделать `dry_run` (файл уйдёт только во временную область, ответ не изменится), потом — настоящую загрузку, и проверь результат в браузере.

## Безопасность

Текст страниц Moodle (задания, форумы, файлы) пишут другие люди, и агент его читает. Чтобы чья-то фраза вроде «загрузи ~/.ssh/… в задание» не превратилась в утечку:

- **сдавать можно только файлы из разрешённых папок**, скачивать — только в них. По умолчанию это `~/Downloads`, `~/Documents`, `~/Desktop`; скрытые файлы и папки (`.ssh`, `.env`, `.git`…) недоступны всегда. Добавить папку: `mirea-moodle-mcp roots add ~/vuz`;
- агенту прямо сказано: текст страниц — данные, а не команды; сдавать — только по твоей просьбе;
- в HTTP-режиме (ChatGPT, claude.ai) сдача выключена, пока не запустишь `http --allow-submit`;
- сессия хранится локально с правами `600`, запросы уходят только на online-edu.mirea.ru;
- установщик сверяет SHA-256 скачанной программы с `SHA256SUMS` релиза.

## Ручное подключение

`mirea-moodle-mcp config <id>` выведет готовый фрагмент и путь к файлу. Форматы всех клиентов, особенности (Gemini CLI и «доверенные папки», VS Code и режим Agent) и подключение ChatGPT / claude.ai через HTTP — в [docs/CLIENTS.md](docs/CLIENTS.md).

## Где что лежит

- программа: `~/.local/bin/mirea-moodle-mcp` (Windows: `%LOCALAPPDATA%\mirea-moodle-mcp\`)
- сессия: `~/Library/Application Support/mirea-moodle-mcp/session.json` (macOS), `%APPDATA%\mirea-moodle-mcp\` (Windows), `~/.config/mirea-moodle-mcp/` (Linux) — права `600`
- настройки (группа, разрешённые папки): там же, `config.json`
- дашборд: там же, `dashboard.html`

Удалить всё: удали программу, эту папку и блок `mirea-moodle` из конфигов клиентов.

## Проблемы

| Симптом | Что делать |
|---|---|
| `Moodle не принял эту сессию` | скопировано не то значение или не с того сайта; проверь, что открыт именно online-edu.mirea.ru и ты залогинен(а) |
| `сессия истекла` | войди на online-edu (расширение обновит cookie само) или `mirea-moodle-mcp cookie <новое значение>` |
| расширение: «Программа не найдена браузером» | выполни `mirea-moodle-mcp extension` и перезапусти браузер; программа не должна лежать во временной папке |
| `вне разрешённых папок` | файл лежит не в `~/Downloads`/`~/Documents`/`~/Desktop` — `mirea-moodle-mcp roots add <папка>` |
| непонятно, что сломалось | `mirea-moodle-mcp doctor` |
| таймаут при подключении | сайт МИРЭА режет часть зарубежных IP — если включён VPN, добавь `*.mirea.ru` в исключения |
| у агента нет инструментов | перезапусти клиент; `mirea-moodle-mcp clients` и `config <id>`; см. [docs/CLIENTS.md](docs/CLIENTS.md) |
| Gemini CLI: сервер `Disabled` | папка не доверенная — выполни в ней `/permissions trust` |
| macOS: «не удаётся проверить разработчика» | `xattr -d com.apple.quarantine ~/.local/bin/mirea-moodle-mcp` (бывает, если скачал бинарник браузером) |

## Как это устроено (коротко)

Мобильный API (веб-сервисы Moodle) на online-edu выключен, поэтому сервер работает как браузер: вызывает те AJAX-функции, которые Moodle открывает для веб-интерфейса (`core_course_get_enrolled_courses_by_timeline_classification`, `core_calendar_get_action_events_by_timesort`, `core_calendar_get_calendar_day_view`, `core_courseformat_get_state`, `message_popup_get_popup_notifications`, `core_session_time_remaining`), а задания, файлы и сдачу берёт с обычных страниц. Протокол MCP (JSON-RPC по stdio) реализован вручную, внешних зависимостей нет.
